# npp-guide
Guidance for NTU undergraduates applying to Master or PhD programmes

1. NPP是什么
   NPP，即 NTU Promotion Programme，是一个面向于NTU本科生的研究生和博士申请的开放交流社区，由三位NTU本科生共同创建。
   我们构建这个社区的目的在于可以整合历届优秀学长学姐的申请信息，同时为即将准备申请或者有申请意愿的同学构建一个交流的平台

2. NPP的目标人群：
   NPP项目的目标人群为现在本科就读于NTU，具有一定的学术理想和追求，准备深造的同学。
   同时我们会邀请毕业的校友在此社区进行经验的分享，并且通过Q&A的形式来帮助解决同学们在申请过程中的痛点

3. 为什么我们需要NPP
   在NPP创建的2026年，研究型硕士和博士的申请已经进入白热化阶段，尤其是在Agent能力如此强大的当下，本科生手握两三篇顶会似乎已经是稀松平常。agent时代前具有强烈的稀缺属性和较难灌水的paper在agent时代变得不再稀缺，正在逐    渐从有paper加分变成无paper减分。那么，在agent时代，申请过程中真正稀缺的东西到底是什么。私以为是通过与目标教授有过的合作经历以及由此建立的connection。在本人申请的过程中，就发现了有不少本科来自NTU，目前在各大顶尖     高校就读PhD的学长和学姐，有不少都在跟随各自领域的大牛。从本科生的视角来看，这些学长学姐就是我们宝贵的校友资源和人脉关系，也是我们进入科研的引领者。
   为此，我们创建了NPP这样一个平台，诚挚地邀请各位在读的本科生和已经毕业的校友来共同创建这样一个平台，可以帮助本科生寻找一些更好的研究机会和资源，构建一个更加美好的NTU的科研校友网。
